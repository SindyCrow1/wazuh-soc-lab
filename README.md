# 🛡️ Detection Lab: Wazuh SOC & Active Response

## 📌 О проекте
Учебная лаборатория по кибербезопасности, развернутая на VPS (Debian 13). Проект демонстрирует полный цикл работы SOC-аналитика: от развертывания SIEM до обнаружения и автоматического реагирования на инциденты.

## 🏗 Архитектура
- **Хост:** VPS (Debian 13, 8 vCPU, 8 GB RAM).
- **SIEM:** Wazuh 4.9.0 (Manager, Indexer, Dashboard) в Docker.
- **Мишень (Victim):** Docker-контейнер (SSH, слабый пароль).
- **Атакующий:** Локальный ПК (имитация брутфорса через Hydra/sshpass).

## 🚀 Реализованный функционал
1. **Сбор логов:** Настроен сбор событий SSH с контейнера-мишени.
2. **Кастомные правила (Detection Engineering):** Написано правило `100100` для обнаружения брутфорса.
3. **MITRE ATT&CK:** Алерты маппятся на технику T1110 (Brute Force).
4. **Active Response (SOAR):** Настроен скрипт `fake-block.sh`, который автоматически логирует блокировку IP-адреса атакующего при срабатывании правила.
5. Мониторинг веб-атак: Настроен сбор логов Apache (DVWA) и правило 100200 для обнаружения SQL-инъекций (T1190).
